# NPC pass: placement loadouts, one talk line each, idle paths, guards' alarm, walk-in lines

Date: 2026-10-16 · Agent: Claude Code · Commit: NPCs as placed: own loadout, one line, idle paths, guards' alarm, walk-in lines

## Why
Ursan and the Ws9a Old Guard held a sword and shield the original does not show; the Old Guard
walked into the wall; striking a peaceful creature did not bring the guards; "Celestia is
expecting you" never played. The user asked for a full NPC pass against the original.

## Decisions and evidence (executable-analysis.md §18)
- Loadout = the cap's inventory header (stats +0x1B0 = XP block − 0x10: weapon slot +0x0A,
  shield +0x0C; slots 0x44 bytes, name +0x24). The template (0x44D9D0) only applies to creatures
  the engine builds. Applies to hostiles too (skeletons with/without shields, axes, ...).
- Talk = one line per placement (stats +0x1E4; −1 = silent, 1,712 of 2,037), gesture ASM state at
  idle behaviour +0x3C (0x40E8C0), use-key reach 12 ft (0x40DEB0). The rotating voice-role lines
  are kept only for synthetic arenas (no placement).
- Peaceful creatures stop and face the player within 12 ft, resume after ≥ 3 s once he is past
  20 ft (brain mode 2, 0x40C520 / 0x40C190 / 0x408980).
- Idle: kind 0 stands (Ws9a prisoners), kind 1 walks its path, 1 s pause per point, back and
  forth (0x405AC0 / 0x405FF0). The random 4 m citizen stroll (invented) is gone.
- Alarm: a player's blow on a disposition 0–2 creature sets 0x52FDC8 for one frame (0x40F890);
  every peaceful creature that sees him (ray 0x406AF0, no range) targets him (0x40D910): armed
  ones fight, unarmed run. Hitting hostiles no longer scares citizens (it did before).
- "Celestia is expecting you" is a walk-in sound trigger (type 0x0B, bit 0, 0x200) in Ci1b, not a
  talk line; 14 dialogue sound triggers exist (Ci1b, Ci4a, Gl2a, train).
- Side quests (26 in 0x497670) have no giver, talk trigger or quest trigger in any shipped act:
  unshipped in the original, so not implemented. No shop exists; merchants are silent NPCs.

## Deviations from the original
- Walk-in lines go to the player who entered only (MMO); non-0x200 ones replay on each entry.
- Path arrival radius 0.4 m and the watch turn (MOB_TURN_RATE) are not decoded.
- Talk-trigger NPCs (+0x1F0 with 0x2000000) are not wired: none ship.
- The client's random idle gestures/alt stands for peaceful creatures are kept (origin unverified).

## Gotchas
- `MANIFEST_VERSION` 1.24.0: run `pnpm convert` and restart the server. Older placements have no
  `held` and keep the template loadout.
- `mobSpawns[].weapon/shield`: `null` = empty hands, `undefined` = archetype's. An Old Guard holding
  nothing is a "citizen" to the server (runs, never fights).
- The client resolves held models per placement before entities spawn (`loadPlacementLooks`,
  awaited in `showArena`).
