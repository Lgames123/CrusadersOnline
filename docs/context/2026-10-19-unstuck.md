# Unstuck in the options menu

Date: 2026-10-19 · Agent: Claude Code · Commit: Unstuck button in the Esc menu puts the character back at its respawn spot

## Why
A player wedged in level geometry had no way out but dying or logging out.

## Decisions and evidence
- Esc menu button (online only, confirm box) → CS_UNSTUCK (0x16) → `WorldZone.unstuck` → the same `toRespawnSpot` the fall catch uses: start of the area by the way he came in, or the last fall-catch checkpoint. That spot is known valid, so no search for a "nearest free spot".
- Refused while dead, in a sequence or frozen; 30 s cooldown (`UNSTUCK_COOLDOWN`), answered with a Server-tab line either way. Cancels a swing or cast in progress.

## Deviations from the original
- Not original (single player had no such thing); always available online, not offline.

## Gotchas
- Zones run in workers: a new client op needs sessions.ts → zone_host.ts → messages.ts → worker.ts, not just WorldZone.
- Cooldown is per zone instance (resets on zoning), not persisted.

## How to verify
- `tests/unit/unstuck.test.ts`; in game: Esc → Unstuck → "Are you sure?" → Server tab says "You have been moved to a safe place."
